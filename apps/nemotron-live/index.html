ShakeFix Second Opinion · live

The fix is AI-written code too. Before it can merge itself, a second AI checks it changed only what the bug report asked for.

Model: NVIDIA Nemotron Served by Nebius Token Factory One real /chat/completions call per click

The case

A user of SplitPal, a bill-splitting app, couldn't settle a ₹1,000 bill three ways. She shook her phone and said:

"settle button does nothing"

ShakeFix's agents found the cause, a rounding error (3 × ₹333.33 ≠ ₹1,000), and wrote a fix. Replaying her real taps on the old and the fixed app gives 10 behaviour changes across screens, API responses and database writes.

Nine of them are the fix. One is not: the new rounding also changed the tip total on a different bill (#9) that she never opened, from ₹49.99 to ₹50.00. A diff reviewer skims past that. Second Opinion must catch it, or the fix ships a new bug.

Rules label every change first. Nemotron then reasons over the bug report and the replay, and can only make a verdict stricter, never clear a side effect.

Run it live

Click once. The server sends the case to Nemotron on Nebius and shows its verdict. It usually takes 5–30 seconds, because Nemotron reasons before it answers.
