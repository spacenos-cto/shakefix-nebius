# Ledger #5 — Switched to USD but total still shows rupees
- **Route:** /bill/:id
- **Files:** apps/splitpal/src/lib/currency.js:41
- **Root cause:** SYMBOLS is keyed by upper-case codes but formatHeaderTotal looked it up with toLowerCase(), so every currency fell back to the rupee sign. Reoperation: the header also forced Indian digit grouping for every currency (USD 1200000 showed $12,00,000.00).
- **Pattern:** symbol-lookup-case-mismatch
- **Fix:** Look up SYMBOLS with toUpperCase() so the key matches. Use Indian grouping only for INR (and the INR fallback). Removed stale SEEDED BUG B3 comment.
- **Siblings checked:** apps/splitpal/src/lib/currency.js:16 formatMoney (n/a, already uses indian: code === 'INR'), apps/splitpal/src/views/bill.js:67 (n/a, caller only)
